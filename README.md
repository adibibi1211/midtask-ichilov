# מגיעים מוכנים לפגישת טרום ניתוח

יחידת למידה קצרה (SCORM 1.2) למטופלים לקראת פגישת טרום ניתוח.
הלומד עוזר למטופלת בדויה, יעל, לארגן את המידע שקיבלה, לזהות מה חסר, לנסח שאלות ממוקדות ולהחליט למי לפנות.

- **לקוח:** המרכז הרפואי תל אביב (איכילוב), מרפאת טרום ניתוח
- **קורס:** תכנות 3, מטלת אמצע, קבוצה 2
- **מגישות:** עדי ביבי, אור לנציאנו

## מבנה היחידה

1. **פתיחה:** הצגת המקרה של יעל.
2. **מה כבר יש בתיק?:** תיק מסמכים אינטראקטיבי (זימון, דף מידע, מחברת).
3. **למי פונים עם מה?:** כרטיסים מתהפכים של אנשי הצוות.
4. **מתרגלים לקראת הפגישה:** שלוש שאלות (בחירה אחת, שאלת יישום על המקרה, התאמה), עם רמז ומשוב לכל שאלה.
5. **השאלות שלי לפגישה:** טופס לבניית רשימת שאלות אישית, עם אפשרות העתקה.
6. **עוד מידע מאיכילוב:** קישורים לאתר בית החולים.
7. **סיום והגשת הלומדה:** הכפתור פעיל רק אחרי מענה על שאלות התרגול ומעבר על כל חלקי היחידה.

כלים שזמינים בכל רגע מהשורה העליונה: הגדלת טקסט (נשמרת בין כניסות), מילון "מושגים חשובים", ועצירת הנפשות.

## העלאה ל-Moodle

1. מעלים את קובץ ה-ZIP כמו שהוא (הקבצים נמצאים ישירות בשורש ה-ZIP, בלי תיקייה פנימית).
2. ב-Moodle: הוספת פעילות ← חבילת SCORM ← בחירת קובץ ה-ZIP.

## מה נשלח למערכת הלמידה

- **שם הלומד:** נשלף מהמערכת ומוצג בפתיחה (שם בפורמט "משפחה, פרטי" מוצג כ"פרטי משפחה").
- **אינטראקציות:** כל בדיקה של שאלה שולחת שתי שורות: התשובה שנבחרה (עם תוצאה ומשקל), ושורת `_hint` שמראה אם נפתח רמז (`t` / `f`).
- **ציון:** נקבע לפי הבדיקה הראשונה של כל שאלה. שאלה 1: 40 נקודות (30 עם רמז), שאלה 2: 20 (15 עם רמז), שאלה 3: 40 (30 עם רמז). תשובה שגויה: 0.
- **סטטוס:** `incomplete` עד ההגשה, ואחריה `passed` (60 ומעלה) או `failed`. הציון נשלח רק בלחיצה על "סיום והגשת הלומדה".
- **המשך מאותו מקום:** מצב הניסיון נשמר ב-`suspend_data`, כך שסגירה באמצע לא מוחקת את התוצאות.
- **מצב צפייה:** כניסה אחרי שהניסיון הושלם לא שולחת נתונים, והלומד מקבל הודעה.

## הרצה מחוץ למערכת הלמידה

פותחים את `index.html` בדפדפן. היחידה עובדת במלואה, ומופיעה הודעה שהתשובות והציון לא יישמרו.

## טכנולוגיות וקרדיטים

- HTML, CSS ו-JavaScript (ללא ספריות נוספות מעבר לרשימה הזו)
- [Bootstrap 5.3.2](https://getbootstrap.com/), רישיון MIT
- [pipwerks SCORM API Wrapper](https://github.com/pipwerks/scorm-api-wrapper), רישיון MIT
- [Rubik](https://github.com/googlefonts/rubik), רישיון SIL OFL 1.1
- הקוד פותח והטקסטים נוסחו בסיוע כלי AI (Claude ו-Codex), ונבדקו ואושרו על ידי הצוות. איורי אנשי הצוות נוצרו בקוד SVG בסיוע Claude.
- הלוגו של איכילוב שייך למרכז הרפואי תל אביב ומשמש לצורכי לימוד בלבד. המקרה של יעל בדוי.
